# 🔬 Skin Lesion Classifier

Классификация дерматоскопических изображений кожных поражений по 7 диагностическим категориям.

⚠️ **Учебный проект, не диагностический инструмент.** Recall на меланоме ~75% — каждый четвёртый случай модель может пропустить. Не заменяет консультацию дерматолога.

## Возможности

- Загрузка дерматоскопического изображения через веб-интерфейс
- Предсказание категории поражения с распределением вероятностей по всем 7 классам

## Модель

- **Архитектура**: ResNet18 (предобучена на ImageNet), дообучены `layer4` и финальный слой
- **Данные**: HAM10000 — 10015 дерматоскопических изображений, 7 классов
- **Точность**: 78% общая, recall на меланоме — 75%
- **Дисбаланс классов**: скорректирован через class weights (класс `nv` составляет 67% датасета)
- **Аугментация**: случайные повороты и отражения (поражения кожи не имеют "правильной" ориентации)

## Известные ограничения

- Разрешение исходных изображений — 112×150, ниже стандартного входа ResNet (224×224) — сеть работает с апскейленными изображениями
- Precision на меланоме всего 42% — модель намеренно склонна к ложным тревогам, чтобы не пропустить реальные случаи
- Обучающие данные — только дерматоскопические снимки (специальным прибором), обычное фото телефоном может давать непредсказуемые результаты

## Стек

- PyTorch + torchvision (обучение с MPS-ускорением на Apple Silicon)
- Streamlit — интерфейс
- scikit-learn — метрики и разбиение данных

## Данные

Оригинальный [HAM10000 dataset](https://doi.org/10.7910/DVN/DBW86T) (Tschandl et al., 2018). В репозитории — только `metadata.csv`; массив изображений (`images.npy`, ~500MB) не хранится в git.

Чтобы восстановить `data/images.npy`, нужен Kaggle-аккаунт и API-токен:
```bash
kaggle datasets download -d proxzima/skin-cancer-mnist-ham10000-pickle -p data --unzip
```
Затем конвертировать pickle (сохранён старой версией pandas) в `.npy` — см. `ARCHITECTURE.md`.

## Запуск

```bash
git clone https://github.com/whyalohadance/skin-lesion-classifier.git
cd skin-lesion-classifier
pip install -r requirements.txt
python3 train.py    # обучит модель, сохранит model.pth
streamlit run app.py
```
